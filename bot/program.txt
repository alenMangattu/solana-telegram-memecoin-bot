This project is a Telegram bot built with Java Spring for creating and trading memecoins on the Solana network, featuring copy trading, automation, and slippage handling, with a focus on modularity and polymorphism for easy scalability and implementation swapping. The structure is organized into clear layers: config for bot and cache settings, controller for handling Telegram updates, service for business logic (trading, Solana interactions, automation), component for handlers and processors managing specific tasks, model for entities and session management, repository for database interactions, utils for reusable logic like slippage calculations, and exception for custom error handling. The bot also includes a robust UI/UX system with state management for navigation (Home, Trading, Settings pages), dynamic keyboard builders, and template engines for message rendering, all while leveraging caching for performance optimization and polymorphism for flexible service implementations.
